Features

Your whole dev loop, in your pocket

Rift is a phone app plus a small agent on your computer. Ask Claude for a change, check the diff, watch it run, then commit, all from your phone.

Chat with Claude Code

A full Claude Code session on your Mac, driven from your phone.

  • Approve tools and answer Claude's questions
  • Attach photos, PDFs and files
  • Pick model, effort and permission mode
  • Have replies read aloud

Review changes and use git

See every file Claude touched, including files changed by shell commands.

  • Inline diffs
  • Git graph with branches, tags and history
  • Commit and push with one tap

Live simulators and emulators

Stream an iOS Simulator or Android emulator to your phone and use it like the real thing.

  • Touch and keyboard control
  • Full-screen mirror
  • Boot any simulator or emulator

Web previews

For web projects, start your dev servers and see the page live from a Chrome window on your Mac.

  • Start and stop servers, with logs
  • Phone, tablet, laptop and desktop sizes
  • Claude can read console errors and take screenshots

Run and hot reload

Run Flutter, React Native and native iOS or Android apps. Your launch.json configurations work too.

  • Auto hot reload after Claude edits Dart files
  • Detects Laravel, Django, Rails and dev scripts
  • Built-in terminal

Quota guard

When you hit your plan limit, or extra paid usage would start, Rift stops prompting and notifies your phone.

  • Never resumes on its own
  • Live plan usage and time to reset
  • Buttons like run, diff and commit use no quota

Security

An agent that can run code deserves care

Rift can edit files and run commands on your computer, so it's locked down by default.

Local only

The agent listens on 127.0.0.1. Your phone reaches it only through tailscale serve inside your tailnet, never Funnel.

Revocable device tokens

Each paired phone gets a random 256-bit token. Only its hash is stored, and you can revoke it any time.

Approve before it runs

By default Claude asks before running tools, and you approve from your phone.

Folders you choose

Projects open only inside allowed folders, such as ~/Workspace. Symlink escapes are blocked.

Biometric lock

The app asks for Face ID or your fingerprint when you open it.

Quiet notifications

Push notifications carry generic text only. No code, commands or file paths.

What you need

Before you start

Everyone

  • A Mac (or a Windows PC for Android and web)
  • Tailscale on your computer and phone, same account
  • Claude Code, logged in with your Claude plan, for chat. Devices and previews work without it.
  • Keep the computer awake: plugged in, lid open (or closed with an external display). The screen can lock.

Depending on what you build

  • iOS: Xcode
  • Android: the Android SDK and an emulator
  • Flutter / React Native: their usual toolchains
  • Web: Google Chrome and ffmpeg

FAQ

Questions

Do I need an Anthropic API key?

No. Rift uses the Claude Code login on your computer. It removes API-key variables from Claude's environment and refuses to run if a key would be used, so you're never billed per token by Rift.

Does my Mac need to stay unlocked?

No. The screen can lock and the display can sleep. Video comes straight from the simulator or emulator, not from your Mac's screen. The Mac does need to stay awake: plugged in with the lid open, or closed with an external display.

Does it work away from home?

Yes. Rift connects over Tailscale, so it works on mobile data or any Wi-Fi, as long as your phone and computer are signed in to the same Tailscale account.

What happens when I hit my Claude plan limit?

Rift stops sending prompts and notifies your phone. It won't continue into extra paid usage, and it won't resume on its own. You pick it back up after your limit resets.

Can I use it without Claude Code?

Yes. Simulators, emulators, web previews, dev servers and git work without it. You only need Claude Code for chat.

Does it work on Windows?

Rift Desktop runs on Windows with Android emulators and web previews. iOS simulators need a Mac.
