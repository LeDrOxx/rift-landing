Terminal

A real terminal on your Mac, in your pocket

When a button isn't enough, open a shell. It's your own terminal running on your computer, not a cloud sandbox.

  • Your shell, your setup. zsh or bash on macOS, PowerShell on Windows, with your PATH and tools.
  • Up to 6 terminals. They keep running when you close the app.
  • Pick up where you left off. Reopen a terminal and its recent output is still there.
  • Keys you need on a phone: esc, tab, ctrl and arrows, one tap away.
  • Anything you'd type at your desk: tests, installs, scripts, git, deploys.

Git

Full git, not just a diff viewer

Review what changed, then do the real work: branch, merge, rebase, fix history and push. Every action is a tap, no prompt needed.

  • Live graph of branches, tags and remotes
  • Full-file diffs with word-level highlights
  • Branches and tags: check out, create, rename, delete
  • Merge, rebase, cherry-pick and revert
  • Commit and push, including force-with-lease
  • Fetch and pull from your remotes
  • Stash, apply and drop
  • Edit commit messages on your branch
  • Safe resets: a hard reset stashes your work first
  • Conflicts: continue or abort a stopped merge or rebase
  • Discard a file, with undo
  • See what one prompt changed, apart from the rest

Security

An agent that can run code deserves care

Rift can edit files and run commands on your computer, so it's locked down by default.

Local only

The agent listens on 127.0.0.1. Your phone reaches it only through tailscale serve inside your tailnet, never Funnel.

Revocable device tokens

Each paired phone gets a random 256-bit token. Only its hash is stored, and you can revoke it any time.

Approve before it runs

By default Claude asks before running tools, and you approve from your phone.

Folders you choose

Projects open only inside allowed folders, such as ~/Workspace. Symlink escapes are blocked.

Biometric lock

The app asks for Face ID or your fingerprint when you open it.

Quiet notifications

Push notifications carry generic text only. No code, commands or file paths.

What you need

Everyone

  • A Mac (or a Windows PC for Android and web)

FAQ

Questions

Does Rift include Claude?

No. Rift runs Claude Code that you install and set up yourself on your computer, under your own agreement with Anthropic. Rift doesn't sell, include or resell any Claude usage.

Does my Mac need to stay unlocked?

No. The screen can lock and the display can sleep. Video comes straight from the simulator or emulator, not from your Mac's screen. The Mac does need to stay awake: plugged in with the lid open, or closed with an external display.

Does it work away from home?

Yes. Rift connects over Tailscale, so it works on mobile data or any Wi-Fi, as long as your phone and computer are signed in to the same Tailscale account.

Can I use it without Claude Code?

Yes. Simulators, emulators, web previews, dev servers and git work without it. You only need Claude Code for chat.

Does it work on Windows?

Rift Desktop runs on Windows with Android emulators and web previews. iOS simulators need a Mac.
