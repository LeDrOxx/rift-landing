Zero Cloud Relays. Complete Privacy.

Built for sensitive production codebases

• Local Loopback Only: The Rift agent listens strictly on 127.0.0.1. No public ports are ever exposed.

• Strict Tailnet Isolation: Remote phone traffic is only permitted via private Tailscale tunnels within your authenticated personal network, never public Funnels.

• Cryptographic Device Tokens: Pairing tokens are 256-bit random entropy. Only their SHA hashes are persisted. You can revoke any device instantly with rift revoke <id>.

• Directory Traversal Sandbox: The agent restricts project opens to configured directory roots (e.g., ~/Workspace). Symlink escapes are rejected.

Frequently Asked Questions

Got Questions? We Have Answers.

Do I need an Anthropic API key to use Rift?

No. Rift is built directly around your existing Claude Code subscription. The agent strips API keys from Claude's environment and verifies your account subscription so you don't incur per-token API charges.

Does Rift wake up my Mac screen or require it to stay unlocked?

No! Mirroring comes directly from the simulator processes (idb_companion for iOS and scrcpy for Android) and headless Chrome over WebRTC. Your Mac can stay locked and the display can sleep.

Can Rift work over cellular or outside my home Wi-Fi?

Yes. Rift uses Tailscale to establish an encrypted, peer-to-peer connection between your phone and your Mac. You can be anywhere in the world on LTE/5G or any Wi-Fi network.

What happens when Claude hits the plan quota?

Rift's Quota Guard intercepts the limit. Instead of continuing into extra paid usage, it pauses prompting and sends a push notification to your phone. Prompts resume cleanly once the reset window opens.
