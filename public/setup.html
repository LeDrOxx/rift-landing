Setup guide

Set up Rift in a few minutes

Install Rift on your computer, connect it to your phone over Tailscale, and you can code from anywhere. Rift Desktop has a button for every step.

Rift is in early access. The phone app is coming soon to the App Store and Google Play. Email us to get it early.

Before you start

Everyone

  • A Mac, or a Windows PC for Android and web
  • An iPhone or Android phone
  • Tailscale on your computer and phone, signed in to the same account
  • For chat: Claude Code installed and set up on your computer. Devices, previews, the terminal and git work without it.

Depending on what you build

  • iOS: Xcode
  • Android: the Android SDK and an emulator
  • Flutter / React Native: their usual toolchains
  • Web: Google Chrome and ffmpeg

Step by step

  1. Install Rift Desktop

    Rift Desktop installs the Rift agent as a login service, so it starts with your computer. It lives in your menu bar, or in the system tray on Windows. From there you can start, stop and restart the agent and open its logs.

    ✓ Rift Desktop shows the agent as running.

  2. Sign in to Claude Code

    Rift runs the Claude Code installed on your computer. If you haven't set it up yet, click Open terminal in Rift Desktop, run claude, and sign in. Skip this step if you only want devices, previews, the terminal and git.

    ✓ Rift Desktop marks the step as done.

  3. Connect Tailscale on your computer

    Install Tailscale and sign in. Then click Enable secure access. This makes the agent reachable only inside your own Tailscale network, never from the public internet. If HTTPS certificates aren't on for your tailnet yet, Rift opens the Tailscale page where you approve them. The first certificate can take about a minute.

    ✓ Rift Desktop shows Tailscale as connected and secure access as on.

  4. Check the connection

    Rift Desktop checks that your computer is reachable at its private .ts.net address. It also runs a preview check that streams real video for a few seconds. If anything fails, the Details panel shows the exact command and its output.

    ✓ Both checks pass.

  5. Install Rift and Tailscale on your phone

    Install the Rift app and the Tailscale app. Sign in to Tailscale with the same account as your computer, and turn it on. Rift Desktop shows a QR code that opens the right Tailscale download for your phone.

  6. Scan the pairing code

    In Rift Desktop, show the pairing QR code, then scan it with the Rift app. The code works once and expires after 5 minutes. Your phone gets its own device token, and you can revoke it at any time.

    ✓ Your phone appears in the list of paired devices.

Set up device tools (optional)

  • iOS Simulator: install Xcode. Rift Desktop installs the tool it uses to stream the simulator.
  • Android emulator: install the Android SDK, including adb and the emulator, and create a virtual device. Rift finds them automatically.
  • Web previews: install Google Chrome and ffmpeg. Rift detects dev scripts, Laravel, Django and Rails, and your launch.json configurations.

Video comes from the simulator or emulator itself, not from your screen, so it keeps working when your computer's screen is locked.

Turn on notifications (optional)

To get a notification when Claude needs your approval or finishes a task, install the ntfy app on your phone and tap the subscribe link in Rift's Settings. Notifications contain generic text only, never code or file paths.

On Windows

Rift Desktop runs on Windows with Android emulators, web previews, the terminal (PowerShell) and git. iOS simulators need a Mac.

Use it from your editor too

The VS Code extension and the JetBrains plugin (2025.1 and later) put the same Claude chat inside your editor, in the same live session as your phone. Both use the agent installed by Rift Desktop. Android Studio needs a runtime with JCEF.

Next: open a project

  • Projects open only inside folders you allow. By default these are ~/Workspace and ~/StudioProjects.
  • By default, Claude asks before running tools, and you approve each one from your phone.
  • Keep your computer awake: plugged in with the lid open, or closed with an external display. The screen can lock.
