FAQ

Answers about Tailscale, Claude Code, devices and security. Read the FAQ.

What to include in your email

  • Your phone model and its iOS or Android version
  • Your computer and its macOS or Windows version
  • The version numbers of the Rift app and Rift Desktop
  • What you did, what you expected, and what happened instead
  • A screenshot, or the result of the connection check in Rift Desktop, if you have one

Please don't send passwords, tokens or private code.

Common problems

The pairing QR code doesn't work

  • Pairing codes work once and expire after 5 minutes. Show a new code in Rift Desktop.
  • Make sure Tailscale is on and connected on your phone.
  • Your phone and computer must be signed in to the same Tailscale account.

The app can't reach my computer

  • Check that your computer is awake and that Rift Desktop shows the agent as running.
  • Check that Tailscale is running on both devices.
  • On your phone, turn on Use Tailscale DNS in the Tailscale app, so addresses ending in .ts.net work.
  • Run the connection check in Rift Desktop. It tells you which step fails and offers a fix.

It stops working when I walk away

Your computer has to stay awake: plugged in with the lid open, or closed with an external display. The screen can lock and the display can sleep.

My simulator or emulator doesn't show up

  • iOS: you need a Mac with Xcode. Rift Desktop installs the tool that streams the simulator.
  • Android: install the Android SDK and create an emulator. Then boot it from the Device tab.

The web preview is blank

Web previews need Google Chrome and ffmpeg on your computer, and a dev server that's running. Start the server from the Preview tab, then open the page.

Chat doesn't work

Rift runs the Claude Code installed on your computer. It doesn't include Claude. Open a terminal on your computer, run claude, and finish signing in. Then try again from your phone. Devices, previews, the terminal and git work without Claude Code.

I don't get notifications

Install the ntfy app on your phone, then use the subscribe link in Rift's Settings. If you've muted notifications from the app or from VS Code, turn them back on.

I lost my phone

Revoke the phone from your computer. In a terminal, run rift devices, then rift revoke <id>. Its token stops working right away. If someone else has the phone, the app lock still protects Rift.

Report a security issue

Email support@riftassistant.com with "Security" in the subject. Please give us a chance to fix the issue before you share it publicly.
